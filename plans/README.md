# Weekly meal plans

Each ISO-week folder contains the printable menu source, taste portrait, machine-readable profile, and rendered PDF for that week.

- `weekly-meal-plan.md` — editable checklist source
- `taste-profile.md` — human-readable preference summary
- `meal-profile.json` — structured profile used for planning
- `weekly-meal-plan-printable.pdf` — A4 print-ready export
