# 本周吃什么：画像驱动的可打印执行单

**本周原则：** 晚餐两人份、周末不在家吃。工作日至少选 **3 顿清淡主菜**，重口菜最多 2 顿；清淡主菜不是重口菜少放辣。螃蟹、小龙虾、海鲜饭、红酒炖牛肉和海参炖鸡仅留到周末有时间时做。

> 口味画像：核心是农家小炒肉、水煮牛肉、麻辣香锅、辣椒炒肉、刺身/炙烤寿司、打抛饭与高分海鲜。西蓝花、日式炒乌冬、意面、冷奴不买不做。

---

## 0. 先核对现有库存

- [ ] 厚切冷冻牛排：12 块
- [ ] 肥羊卷：两板合计 `400g`
- [ ] 冷冻鸡胸肉：至少 `600g`（不作为默认工作日晚餐，留作辣子鸡丁/宫保鸡丁）
- [ ] 发好冷冻海参：本周不解冻
- [ ] 沙姜盐焗鸡粉、鳗鱼饭汁、常见调料、大米
- [ ] 厨具：燃气灶、电饭锅、烤箱、微波炉、高压锅、喷火枪

### 已购库存：优先消耗，不重复买

- [ ] 鸡翅 `800g`
- [ ] 里脊 `200g`
- [ ] 梅花肉 `300g`
- [ ] 清油火锅底料 `1 袋`

## 1. 采购：冷冻多备，鲜菜少买

### 冷冻储备：分装后慢慢吃

- [ ] 去皮鸡腿肉 `1kg`：`500g x 2`；椰子鸡 1 袋、姜葱鸡腿 1 袋
- [ ] 肥牛片/牛里脊片 `500g`：分 `250g x 2`；水煮牛肉 1 袋、备用 1 袋
- [ ] 不再购买猪肉：已有里脊 `200g`、梅花肉 `300g`
- [ ] 去壳生虾仁 `500g`：分 `250g x 2`；虾仁滑蛋 1 袋、麻辣香锅/备用 1 袋
- [ ] 不再购买鸡翅：已有 `800g`，可做一顿盐焗鸡翅

### 本周鲜食：只买近期用量

- [ ] NFC 椰子水 `1L`
- [ ] 冬瓜 `400g`、娃娃菜 `250g`、姜 `1 块`（椰子鸡）
- [ ] 鲜香菇/白玉菇 `250g`、小青菜 `250g`（姜葱鸡腿）
- [ ] 鸡蛋 `6 个`、小青菜 `250g`（虾仁滑蛋）
- [ ] 大葱 `250g`、空心菜/通菜 `250g`（肥羊）
- [ ] 青尖椒或螺丝椒 `250g`、蒜苗 `100g`（辣椒炒肉/农家小炒肉）
- [ ] 金针菇或白玉菇 `250g`、小青菜 `250g`（水煮牛肉原味底）
- [ ] 土豆 `500g`、彩椒 `2 个`、洋葱 `1 个`（决定吃牛排当天再买也可）
- [ ] 小葱 `1 把`、鸡蛋 `4 个`、挂面 `1 包`
- [ ] 吐司 `1 条`、芝士片 `1 包`、蛋黄酱 `1 小瓶`（单人早餐）

### 只在当天购买

- [ ] 炙烤寿司：寿司米/寿司醋、黄瓜、牛油果（可选）
- [ ] 需要麻辣香锅：当天补喜欢的耐煮菜与豆制品；不买西蓝花

## 2. 采购回家后：预处理任务

- [ ] 鸡腿肉 `1kg` 分成 `500g x 2`，一袋标“椰子鸡”，一袋标“姜葱鸡腿”，冷冻。
- [ ] 牛肉片 `500g` 分成 `250g x 2`；一袋标“水煮牛肉”，冷冻。
- [ ] 里脊 `200g` 标“辣椒炒肉”；梅花肉 `300g` 标“农家小炒肉”，分别冷藏或冷冻。
- [ ] 虾仁 `500g` 分成 `250g x 2`，冷冻。
- [ ] 鸡翅 `800g` 做一顿盐焗；吃前用盐焗鸡粉、姜片、少量油腌 30 分钟。
- [ ] 大葱斜切，葱白/葱绿分开密封，标“肥羊”。
- [ ] 叶菜当天买当天洗；完全沥干再下锅，不提前囤两餐量。
- [ ] 牛排：只有决定明天吃时，前一晚把两块移到冷藏室下层解冻。

---

## 3. 工作日快手任务池

### A. 清淡主菜优先：一周至少选 3 顿

### ☐ 椰子鸡 + 冬瓜娃娃菜 + 米饭（20 分钟）

- [ ] 鸡腿 `500g`、椰子水 `1L`、清水 `200ml`、姜片、冬瓜 `400g` 煮沸。
- [ ] 保持微沸 8 分钟，下娃娃菜再煮 3-4 分钟，盐 `3-4g` 调味。
- [ ] 原味版：直接盛鸡、菜和汤。
- [ ] 加辣版：生抽、沙姜末、蒜末、辣椒油另蘸。

### ☐ 姜葱鸡腿 + 菌菇青菜 + 米饭（20 分钟）

- [ ] 鸡腿 `500g` 前一晚移冷藏；菌菇 `250g`、小青菜 `250g` 洗净。
- [ ] 鸡腿以盐 `3g`、白胡椒、料酒 `5ml` 抓匀；热锅少油煎至两面上色。
- [ ] 下姜片、葱白和菌菇，加清水 `80ml`，盖盖焖 6-8 分钟至熟。
- [ ] 下小青菜、葱绿，盐和少量生抽调味后出锅。
- [ ] 全程不放辣；如需重口，仅在另一份成品上另加辣椒油。

### ☐ 虾仁滑蛋 + 青菜 + 米饭（15 分钟）

- [ ] 虾仁 `250g` 前一晚移冷藏；鸡蛋 `4 个` 加盐、白胡椒和温水 `30ml` 打散。
- [ ] 虾仁用少量油滑熟后盛出；鸡蛋液入锅，半凝固时放回虾仁，轻推至嫩熟。
- [ ] 青菜焯熟或蒜蓉快炒；清淡版直接上桌。
- [ ] 如需加辣，只在成品另加辣椒油，不改变主锅调味。

### ☐ 厚切牛排 + 烤土豆彩椒（45-55 分钟）

- [ ] 确认两块牛排已在冷藏室彻底解冻。
- [ ] 土豆 `500g` 拌油、盐、黑胡椒，`210C` 烤 20 分钟；加彩椒、洋葱再烤 15 分钟。
- [ ] 牛排擦干、重盐和黑胡椒；煎/烤至喜欢熟度，静置 5-8 分钟。
- [ ] 原味版只用盐黑胡椒；加辣版切片后加辣椒油或黑椒汁。

### B. 重口轮换：一周最多选 2 顿

### ☐ 清油火锅（25 分钟，一锅完成四类）

- [ ] 清油火锅底料按包装说明加水煮开，汤底即为“汤”。
- [ ] 荤菜：里脊 `200g` 或梅花肉 `200g` 切薄片；半荤：豆腐/虾滑/鸡蛋任选一份。
- [ ] 素菜：当天购买娃娃菜、空心菜、菌菇、冬瓜等 `500-700g`；不买西蓝花。
- [ ] 原味版：先用清水或未加底料的小锅烫熟肉、菜和半荤，再盛出。
- [ ] 加辣版：清油火锅底料另锅煮；不要用同一锅把原味食材煮辣。

### ☐ 大葱炒肥羊 + 通菜 + 米饭（15 分钟）

- [ ] 两板肥羊卷合计 `400g` 提前冷藏解冻；电饭锅煮米 `180g`。
- [ ] 热锅不放油，羊肉刚变色就盛出并倒掉析出的油。
- [ ] 葱白炒香，羊肉回锅，加生抽 `10ml`、料酒 `5ml`；下葱绿翻 10 秒。
- [ ] 蒜蓉快炒通菜。
- [ ] 原味版先盛；加辣版再加孜然、辣椒面或辣椒油。

### ☐ 水煮牛肉：鲜味原味底 + 后置辣油（25 分钟）

- [ ] 牛肉片 `250g` 前一晚移冷藏；加生抽 `8ml`、淀粉 `5g`、油 `5ml` 抓匀。
- [ ] 金针菇/白玉菇和小青菜焯熟铺碗底。
- [ ] 清汤或高汤加姜蒜、少量生抽煮开，牛肉滑熟 1 分钟，先盛原味份。
- [ ] 剩余汤和牛肉加辣椒油、花椒油、干辣椒；不要让原味份接触辣椒。

### ☐ 农家小炒肉/辣椒炒肉 + 米饭（20 分钟）

- [ ] 里脊 `200g` 做辣椒炒肉，或梅花肉 `300g` 做农家小炒肉；前一晚移冷藏。青椒 `250g`、蒜苗 `100g` 切好。
- [ ] 肉片以生抽、料酒、淀粉抓匀，热锅快炒至变色后先盛。
- [ ] 青椒、蒜苗炒香，肉回锅；原味版用生抽和少量蚝油收味。
- [ ] 加辣版另加小米椒、豆豉或辣椒油；不把辣椒混进原味锅底。

### ☐ 盐焗烤鸡翅 + 蒜蓉通菜 + 米饭（35 分钟）

- [ ] 鸡翅 `800g` 拌沙姜盐焗鸡粉 `20-25g`、姜片、油 `8g`。
- [ ] 烤箱 `200C` 烤 25 分钟，翻面再烤 8-12 分钟；中心必须熟透。
- [ ] 通菜 `250g` 蒜蓉快炒；加辣版用辣椒油单独蘸。
- [ ] 如有余肉且不影响晚餐，再留 2-3 个鸡翅的肉做 1-2 份鸡肉芝士三明治。

### C. 当天鲜货：确认购买后再选

### ☐ 炙烤寿司（20 分钟，当天买）

- [ ] 当天购买明确标示可生食、全程冷链的三文鱼/北极贝/鲷鱼 `300-360g`。
- [ ] 生米 `180g` 煮熟后趁热拌寿司醋 `30ml`，摊开降温。
- [ ] 捏寿司饭团，放刺身；喷火枪只短暂炙表面，避免加热过度。
- [ ] 当天吃完；温度、气味异常时改为彻底煎熟。

## 4. 单人早餐与即时主食

### ☐ 鸡肉芝士三明治（2 份）

- [ ] 用盐焗鸡肉、蛋黄酱、芝士片夹吐司；冷藏最多 2 天。
- [ ] 微波 `700-800W` 45-60 秒；黄瓜想脆则复热后再放。

### ☐ 阳春面 + 煎蛋（8 分钟）

- [ ] 挂面 `80-100g` 煮熟。
- [ ] 碗中放生抽 `10ml`、猪油或芝麻油 `5ml`、小葱、热面汤 `150ml`。
- [ ] 煎 1 个鸡蛋放面上，现做现吃。

## 7. 收尾与食安

- [ ] 生肉、熟食、刺身使用不同砧板和刀具；接触生肉后洗手。
- [ ] 鸡肉、虾仁和牛肉确保中心熟透；刺身仅当天食用。
- [ ] 熟菜冷藏最多 3 天；三明治最多 2 天。
- [ ] 叶菜优先当天补货；肉类按单餐分装冷冻，前一晚冷藏解冻。
- [ ] 西蓝花、日式炒乌冬、意面、冷奴不进入采购或随机菜单。
